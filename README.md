# AI & Data analysis projects from the university
Various projects related to AI and data analysis that were done by me during my studies at Gdansk University of Technology (Politechnika Gdańska).

## Description of projects (subjects)
Each folder in this repository is related to only one subject from the university. Here is a description for each of the subjects.

### Advanced Data Mining
Each laboratory (task) consists of one folder and is on a different topic:
- Linear regression and classification (*task1*)
- Data visualization (*task2*)
- Exploratory Data Analysis (EDA) (*task3*)
- Decision trees & Random forests (*task4*)
- Feature selection, extraction & parameter tuning (*task5*)
- Network (graph) data (*task6*)
- Collaborative Filtering vs Naive algorithms (*task7*)

### Data Mining
This subject consisted of 2 parts:
1. **EDA**: EDA of League of Legends ranked games (*EDA_Legue.ipynb*)
2. KNIME project

### Big Data
The subject was about:
- Apache Hadoop
- MapReduce (in Java)
- Databricks

### Big Data 2
This subject was about the creation of **SPARQL queries (RDF)**.

### Data Visualization
This subject included data preparation and visualization of GeoJSON data.

### Deep Neural Networks
The goal of the project was to train a model on Sign Language MNIST in order to classify sign language
signs with 95% accuracy given correctly formatted input images.

The description is provided in the *DNN - phase 1.pdf* and other reports.

### Artificial Intelligence
Laboratories were about various AI topics:
- Simulated annealing
- Genetic algorithms
- Tree pruning
- Classification (with TensorFlow)

The project was to write the best model using CNNs (Convolutional Neural Networks) for a given dataset. In my case it was about face recognition (*face-recognition-famous48* dataset). Everything is described in the report.
